# RewardLab

Демо механик вовлечения на Flask + SQLite: ежечасный бонус, серия дней, викторина,
реферальная программа с уровнями, недельный конкурс, блэкджек на виртуальные баллы и админ-панель.
Баллы виртуальные: их нельзя купить, продать или вывести.

## Запуск

```
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py           # http://127.0.0.1:5000
```

Настройки окружения — в `.env` (образец: `.env.example`).

Права администратора выдаются только из консоли:

```
.\.venv\Scripts\python.exe app.py make-admin <username>
```

## Структура

```
app.py                     точка входа и консольные команды
rewardlab/
  __init__.py              create_app(): сборка приложения
  config.py                все числа механики (награды, уровни, призы, ставки)
  db.py                    подключение к SQLite, схема, миграции
  security.py              текущий пользователь, CSRF, лимиты попыток, заголовки
  cli.py                   make-admin / remove-admin
  services/                бизнес-логика без HTTP
    points.py              начисление, списание, уведомления, удаление аккаунта
    referrals.py           уровни, доля от заработка друга, активация
    contest.py             недельный конкурс и выдача призов
    blackjack.py           движок блэкджека
    totp.py                одноразовые коды для админки
  blueprints/              HTTP-маршруты по разделам
    main.py                главная, лидеры, правила, конфиденциальность
    auth.py                регистрация, вход, выход, удаление аккаунта
    account.py             дашборд, награда, викторина, друзья
    blackjack.py           стол блэкджека
    admin.py               админ-панель
  templates/               Jinja-шаблоны (base.html + страницы, admin/)
  static/
    css/main.css           стили и две темы
    js/app.js              переключатель темы, таймер, копирование ссылки
    img/                   иконка (SVG + PNG для телефонов)
```

## Палитра «Оазис»

| Роль | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | `#FBF6EC` песок-50 | `#0A1C1B` ночной тил |
| Карточки | `#FFFFFF` | `#102A28` |
| Песок Сахары (плашки, акценты) | `#E9D3A6` / `#F6EAD0` | `#EBD3A3` |
| Дюна (тёплый акцент) | `#C8A26B` | `#C8A26B` |
| Тил (кнопки, ссылки) | `#0F766E` | `#2DD4BF` |
| Небесно-голубой (градиенты, фокус) | `#0284C7` / `#38BDF8` | `#7DD3FC` |
| Текст | `#17312E` | `#F6EBD5` |

Основной градиент: тил → небесно-голубой. Тема выбирается по настройке системы,
кнопка ☀/☾ в меню переключает её вручную. Стол блэкджека оформлен отдельно и от темы не зависит.
